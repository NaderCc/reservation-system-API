Description

POST /wallet/deposit
Description

Add funds to the authenticated user's wallet. The transaction is recorded in the wallet history.

Request Body
Field Type Description
amount number Amount to deposit (must be positive, max 2 decimal places)
Request Example
POST /wallet/deposit HTTP/1.1 Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... Content-Type: application/json { "amount": 1000.50 }
Response (Success - 200 OK)
Status Code: 200 - Deposit processed successfully
{ "success": true, "data": { "transaction_id": "tx-unique-id", "type": "DEPOSIT", "amount": 1000.50, "balance_before": 5000.00, "balance_after": 6000.50, "created_at": "2026-05-25T15:45:00Z" } }
Error Responses
400 Bad Request: Invalid amount format or amount not provided
400 Bad Request: Amount must be positive number
401 Unauthorized: Missing or invalid JWT token
404 Not Found: Wallet not found for user
500 Internal Server Error: Database transaction failed
Note: Deposit transactions are ACID-compliant. If any error occurs during processing, the transaction is automatically rolled back.
